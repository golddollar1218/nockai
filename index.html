Questions & Answers

Short answers about the model, running it and licensing.

NockAI

01What is NockAI?

NockAI is a set of open language models for people who build on and use Robinhood Chain. The first one is Nock Coder, a coding model. More follow once it is tested.

02Which base model is it built on?

Nock Coder is a LoRA fine tune of Qwen2.5 Coder 1.5B Instruct, which is licensed under Apache 2.0. We trained it on short, code first answers.

03Is NockAI affiliated with Robinhood?

No. NockAI is an independent project. Robinhood and Robinhood Chain are trademarks of their owners and are named only to describe what the models are for.

Model & use

04Does it run on my computer?

Yes. We publish a quantized GGUF build for llama.cpp and Ollama. At 1.5 billion parameters it runs on a typical laptop, including one without a dedicated graphics card.

05How good is it?

It is a 1.5B model, so expect mistakes. In our test of 50 prompts, all 50 answers from v2.1 started with code, at about a quarter of the base model's length. On HumanEval it passes 118 of 164 problems, 6 more than the base model. On 15 Solidity tasks, 10 answers compile, against 8 for the base model. Review any code before you run it. See the full results.

06Can I trust its smart contracts?

No model output should go on chain without review. Nock Coder is a drafting aid. Have a qualified person audit any contract before you deploy it.

07Is it free?

Running it on your own machine is free. We release the weights openly and state the license on each model card. A hosted API is also available on Surplus at $0.03 per 1M tokens.

08What data was it trained on?

Short code first answers drawn from two MIT licensed instruction datasets, one general and one for Solidity, plus a few identity examples. Both datasets contain text generated by other language models, and the model card lists them.
